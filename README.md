# 服务部署分发

在一台 Linux 控制机上运行。页面里配置目标 IP，系统调用本机的 `ssh` 和 `scp` 按顺序执行。某一步失败后，该步骤标红，后面的步骤不再执行。

## 准备

控制机需要：

- Python 3.9 或更高版本
- 已安装 `ssh` 和 `scp`
- 能用密钥登录目标机器。页面可以填写私钥路径；留空则使用当前用户的默认密钥。

## 启动

```bash
cd deploy-system
python3 app.py
```

浏览器打开 `http://控制机IP:8787`。

## 怎么用

1. 添加目标机器：名称、IP、端口、用户名。
2. 建立命令方案。远程命令会在目标机器上执行；上传和下载分别对应 `scp`。
3. 选择方案和目标后开始执行。
4. 页面显示每一步的等待、执行中、成功、失败或跳过。失败为红色，并停止后续步骤。

多台机器按选择顺序执行：第一台的全部步骤完成后，才进入下一台。中途失败则全部停止。
